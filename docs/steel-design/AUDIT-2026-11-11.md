# Steel beam-column template audit — 2026-11-11

Audited source: `7befc8b93415c8999d693b76be04e5e4b4163c8e`.
This is a review of the existing template, not a correction or design certification.

## Conclusion

The published benchmark cases pass, and independent Python arithmetic reproduces the default worksheet. It is **not justified to say that every result or every PASS is correct**. The final member check does not incorporate applicability checks, and signed inputs can suppress the calculated demand. These are release-blocking findings for an unrestricted design check.

## Confirmed findings

### 1. Final PASS ignores failed applicability checks — high priority

`tools/templates/gen_steel.mjs`, section 9, defines the final check solely as `UR <= 1`. It does not depend on Class, the Annex B slenderness branch, valid LTB case, the strength limit, or the shear-buckling scope check. Batch output `ok` uses the same expression.

Engine probes against the actual generated template gave:

| Change from default | Governing UR | Final member PASS | Relevant limitation |
|---|---:|---|---|
| None | 0.461763020965 | Yes | Within the displayed scope checks |
| Custom h/b/tf/tw = 600/200/20/10 mm | 0.922767220670 | Yes | Class = 4; Class <= 3 fails |
| Lcr,z = 1 m | 0.375586410943 | Yes | lambda,z >= 0.4 fails; wrong Annex B branch continues |
| LTB case = 2.5 | 0.463151448126 | Yes | LTB validity fails; coefficients are nevertheless interpolated |
| fy = 500 MPa | 0.372474303519 | Yes | fy <= 460 MPa fails |

The earlier local FAIL remains visible. The defect is the misleading final PASS, especially in the batch table where the scope checks are not output columns. A final decision must require both valid scope and resistance checks; an unsupported configuration should be reported as not verified.

### 2. Negative action magnitudes can produce zero utilisation — high priority

Set NEd = 0 kN and My,Ed = -1000 kNm on the default HEB 320 worksheet. There are no calculation errors; governing UR = 0 and Member PASS = true. The sheet asks for magnitudes but does not enforce them. Direct signed divisions create negative utilisation terms, which disappear in the final maximum alongside zero shear/axial terms.

Demand magnitude inputs must be rejected when negative, or normalised explicitly and consistently. The same issue applies to moments and shears; axial tension is outside the declared scope and must be rejected rather than credited.

### 3. High-shear member interaction continues without verification — high priority

With default geometry/actions except Vz,Ed = 700 kN, rho = 0.102022470559, governing UR = 0.659704782770 and Member PASS = true. Section resistance is reduced, but Mb,Rd and Annex B member interaction remain unreduced. The worksheet itself says high shear needs a separate check; that limitation does not block the final result. This probe demonstrates an unverified PASS, not proof that this particular member fails.

The test reference kernel already returns a limitation for high-shear combined member interaction. Its numerical comparison with the worksheet does not test equivalence of the final verification status.

### 4. Input and applicability coverage is incomplete — medium priority

The worksheet does not enforce positive member lengths/stiffness/partial factors or valid Cm inputs. Squared lengths can hide a negative length. The implemented plastic kzy branch is restricted to lambda,z >= 0.4; Class 3 interaction and the short-member branch are not implemented. A declared Class 1–3 cross-section scope is therefore broader than the implemented member interaction scope.

The current reference kernel also flags biaxial shear and torsional-mode-governed combined stability for separate verification; the worksheet summary has no matching guards. These require targeted verification before claiming general combined-action coverage.

### 5. Library properties are not all manufacturer tabulated values — medium priority

For HEB 320, the built-in geometry-derived catalogue gives It = 225.069 cm4. ArcelorMittal's table gives 230.4 cm4, a difference of -2.31%. Area, Iy, Iz and plastic moduli agree closely with the table. The catalogue's torsion approximation must not be described as exact manufacturer data. This particular lower It reduces calculated elastic stability stiffness; no universal conclusion about all catalogue records follows.

The W-section source edition remains undeclared. This audit did not certify every property of all 379 records.

The existing steel-template test passes the JRC column, beam and beam-column benchmarks, the load-height Mcr case and all 13 C1/C2 pairs. Published rounded resistances have explicitly stated tolerances in the test. This is evidence for those cases, not exhaustive verification.

The JRC beam-column example uses Cm = 0.43 and the alternative LTB method; the default template now uses Cm = 1 and the general LTB method. Its final value should not be presented as an exact reproduction of the printed JRC final ratio.
