# Steel beam-column template (EN 1993-1-1)

`templates/Steel_Beam_Column_EC3.mCCV`, generated by `tools/templates/gen_steel.mjs` with the same helpers as the RC column templates (`layout.mjs`). Every result is a worksheet equation and every check is a `UR ≤ 1` region; there is no hidden calculation.

## Scope

EN 1993-1-1:2005 + A1:2014. Uniform, doubly symmetric rolled or custom welded I/H member, Class 1 to 3, compression with bending about both axes and shear. Not covered: Class 4, tension, torsion, shear buckling, holes, fire, connections. A limit that is exceeded fails a visible check (it never passes silently):

| Limit | Check on the sheet |
|---|---|
| Class 4 | `Class ≤ 3` |
| Web needs a shear buckling check | `(h − 2tf)/tw ≤ 72ε/η` |
| Buckling curves outside Table 6.2 range | `fy ≤ 460 MPa` |
| Tabulated C1/C2 with k or kw ≠ 1, or a case that is not 0…13 | `δLT ≥ 1` |
| Annex B plastic factors | `Class ≤ 2`, `λz ≥ 0.4` |

## Method

Presentation separates cross-section resistance (§6.2) from member compression
(§6.3.1), lateral-torsional buckling (§6.3.2.2) and compression/bending interaction
(§6.3.3(4), equations (6.61)/(6.62), Annex B Method 2). Worksheet text and LTB
diagram captions use Roboto. Parameter equations share a fixed x = 396 column;
long equations use a separate x = 96 line below their labels.

The final Member result now requires **both** `delta_scope = 1` and `UR <= 1`.
Summary flags reject negative action magnitudes, nonpositive material/factor/length inputs,
invalid section geometry, out-of-range Cm values and invalid LTB arrangements. They also
exclude unsupported combined interaction: Class 3/4, the lambda,z < 0.4 branch,
high shear with bending, biaxial shear and torsional-mode-governed combined stability.
The web must not be Class 4 under uniform compression when NEd > 0.
Pure compression and pure major-axis bending do not require the plastic interaction branch.
A failed scope flag means **NOT VERIFIED**, even if the separate numerical resistance check passes.
The batch table includes Scope and uses the same combined Member decision; Lcr,T is a per-row input.
Library It/Iw values may be geometry-derived approximations, as stated on the worksheet.
See [the audit and remediation record](AUDIT-2026-11-11.md).

## LTB case table

Annex A.1 stores the 13 LTB cases in a table with loading/support sketches, normalized bending-moment diagrams and editable C1/C2 worksheet cells. The lookup vectors are assembled from those cells, so edits also change Mcr. Values follow [SCI NCCI SN003b Tables 3.1/3.2](https://www.steelconstruction.info/images/0/0f/SN003b.pdf), with k = kw = 1 and the conservative C1 column at κ = 0. Support symbols describe restraints in the bending plane; lateral movement and twist remain restrained at both ends. Case 0 remains available for other arrangements. The two table panels are grouped to print intact.

## Section library

**Insert → Steel Section** opens the picker before changing the worksheet. Choose a library
section or Custom I/H, name its array (S1, S2, etc.), then insert. Cancel creates nothing.
The result is a 19-entry array with units, in the stable `propertyKeys` order (indices 0–18).
Linked variables have distinct names, e.g. `h_{S1} := at(S_1, 0)` and
`A_{S1} := at(S_1, 5)`. Each alias reads the array; changing Browse updates only the array
definition and all references recalculate. A second section gets S2 automatically;
existing array/alias names are rejected. The picker labels every property with its index.

Library arrays contain ordinary `stack(sectionProp(...), ...)` expressions. Custom arrays
use an explicit `let` expression with four literal dimensions and the same rectangle/thin-wall
formulas described below. These bindings are local, so they cannot overwrite worksheet h/b/A.
No calculated properties or new shape metadata are saved. The compact array header shows the
section name; an ordinary evaluation `S_1 =` displays the array values.
Insertion reserves space for the block and forms one undo step. Existing legacy Section-ID
controls and the beam-column template retain their original contract.

`sectionProp(Section, i)` looks a property up in the built-in library (`src/engineering/steel/`, 379 records: IPE, HEA, HEB, HEM, W). The **Browse** button on the `Section` input opens the library and sets the ID. IDs are stable (1000+ IPE, 1100+ HEA, 1200+ HEB, 1300+ HEM, 2000+ W): never renumber.

The worksheet and printed reports display the selected designation, e.g. `Section := HEB 320`, instead of the numeric lookup key. Browse lists sections by name. The underlying numeric definition is preserved for existing documents, property lookup and batch overrides.

Data: IPE/HE from Steel_Section_Database (MIT), geometry-derived properties; W from steelpy (Apache-2.0), AISC values, r = 0. Licences and source files are in `src/engineering/steel/data/`; `tools/templates/import-steel-sections.mjs` rebuilds `catalogue.json`. Check properties against the project section tables.

### Custom welded I/H

Browse → **Custom I/H** accepts overall depth `h`, flange width `b`, flange thickness `tf` and web thickness `tw`, in mm. Both flanges are identical. Inputs must be positive and finite, with `h > 2tf` and `b > tw`. Sharp corners (`r = 0`); weld metal is excluded. The dialog previews all 19 library properties, including mass at 7850 kg/m³ and both radii of gyration.

Section ID **0** identifies a custom welded section. `src/canvas/steelSections.ts` applies the four literal dimensions, section-property equations and buckling-curve definitions as one undo transaction. Inputs and expressions are stored as ordinary LaTeX regions, so save/reload, file export and worker calculation use the same document format. No calculated property is persisted. The custom equations retain a lazy library branch: a Table In&Out case overriding Section with a library ID still uses that section's properties and rolled curves.

For `hw = h − 2tf`, area, second moments and plastic moduli follow rectangle integration. `It ≈ (2b·tf³ + hw·tw³)/3` and `Iw ≈ tf·b³·(h − tf)²/24` use the thin-wall model, without fillet or weld corrections: [SCI P385, Appendix B.2.2 and B.3.1](https://www.steelconstruction.info/images/6/6f/Sci_p385.pdf). These approximations are stated in the dialog and worksheet. The shear areas are `Av,y = 2b·tf` and `Av,z = hw·tw`, with conservative η = 1.0 under EN 1993-1-1:2005 §6.2.6(3); the separate worksheet η input still controls the shear-buckling scope check.

Welded flexural curves follow Table 6.2: b/c for tf ≤ 40 mm, c/d above 40 mm ([SCIA theoretical background](https://help.scia.net/19.1/cs/pvt/steelcodechecktb/en/flexural_buckling.htm)). Welded general-case LTB curves follow Table 6.4: c for h/b ≤ 2, d otherwise ([SCI AD 560](https://www.newsteelconstruction.com/wp/ad-560lateral-torsional-buckling-of-unrestrained-plate-girders/)). Rolled library curves remain unchanged. The shared formula data are in `src/engineering/steel/sectionFormulae.json`; preview arithmetic is checked against independently integrated reference values and the worksheet engine.
